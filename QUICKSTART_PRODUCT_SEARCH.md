# 🚀 Быстрый старт: Поиск товаров по артикулу

## Для пользователей

### Как спросить Алису о товаре?

Просто скажите артикул, произнося каждую цифру отдельно:

```
"Девять пять семь четыре шесть один ноль"
```

или

```
"Артикул девять пять семь четыре шесть один ноль"
```

### Что Алиса ответит?

Алиса расскажет:
1. Код и название товара
2. Краткое описание
3. Основные параметры (цвет, материал, размеры, вес, комплектация)

### Пример

**Вы:** "Артикул девять пять семь четыре шесть один ноль"

**Алиса:** "По коду 9 5 7 4 6 1 0 — товар: Держатель для полотенца Lauter. Коротко: Настенный держатель для полотенец в ванную создает удобное место для банных принадлежностей..."

## Для администраторов

### Первоначальная настройка

```bash
# 1. Установка зависимостей
npm install

# 2. Создание виртуального окружения Python
python3 -m venv venv
source venv/bin/activate
pip install openpyxl pandas

# 3. Конвертация базы данных
python scripts/convert_products_to_json.py

# 4. Запуск навыка
npm start
```

### Обновление базы товаров

```bash
# 1. Обновите Excel файл:
#    Все товары/Описание ДОМа_идеально_для_Алисы_v3.xlsx

# 2. Конвертируйте в JSON:
source venv/bin/activate
python scripts/convert_products_to_json.py

# 3. Перезапустите навык
npm start
```

### Тестирование

```bash
# Быстрый тест одного товара
node scripts/test_single_product.js "девять пять семь четыре шесть один ноль"

# Полный набор тестов
node scripts/test_product_search.js

# Реалистичные сценарии
node scripts/test_realistic_scenarios.js
```

## Поддержка

💡 **Советы:**
- Произносите каждую цифру отдельно
- Минимум 5 цифр для поиска
- Используйте слова "артикул" или "код"

❓ **Проблемы?**
- Проверьте правильность артикула
- Убедитесь, что товар есть в базе данных
- Обратитесь к консультанту
