# 🔍 Инструкция: Поиск товаров по артикулу

## Как спросить Алису о товаре

### ✅ Рекомендуемый способ: произнесение по одной цифре

Просто скажите Алисе артикул, произнося каждую цифру отдельно:

```
"Девять пять семь четыре шесть один ноль"
"Артикул девять пять семь четыре шесть один ноль"
"Код товара девять пять семь четыре шесть один ноль"
```

### Другие способы

**Прямой ввод (если используете текст):**
```
"9574610"
"Артикул 9574610"
```

**Частичный артикул (последние 5+ цифр):**
```
"Семь четыре шесть один ноль"
```

## Что Алиса расскажет о товаре

1. **Код и название** товара (Алиса произнесет код по цифрам)
2. **Краткое описание** товара
3. **Основные параметры:**
   - Цвет
   - Материал
   - Размеры
   - Вес
   - Комплектация

## Примеры

### Пример 1
**Вы:** "Артикул девять пять семь четыре шесть один ноль"

**Алиса:** "Держатель для полотенца Lauter. Настенный держатель для полотенец в ванную создает удобное место для банных принадлежностей. Конструкция из латуни с покрытием цвета хром демонстрирует устойчивость к воздействию влаги..."

### Пример 2
**Вы:** "Девять пять семь четыре четыре девять три"

**Алиса:** "Держатель для полотенца Lauter Поворотный. Настенный держатель для полотенец в ванную создает компактное место для размещения банных принадлежностей. Конструкция из цинкового сплава с покрытием цвета хром..."

## Советы

💡 **Говорите четко** - произносите каждую цифру отдельно  
💡 **Используйте "артикул" или "код"** - это помогает Алисе понять ваше намерение  
💡 **Минимум 5 цифр** - для поиска нужно минимум 5 последних цифр артикула  

## Если товар не найден

Алиса скажет: "Товар с кодом ... не найден в базе данных. Проверьте правильность артикула или обратитесь к консультанту."

В этом случае:
1. Проверьте правильность артикула
2. Попробуйте произнести артикул еще раз
3. Обратитесь к консультанту в фирменной футболке "21 век дом"
