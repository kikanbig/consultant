# Поиск товаров по артикулу

## Обзор

Модуль поиска товаров позволяет Алисе находить и описывать товары из базы данных магазина по их артикулу (коду товара).

## Формат описания товара

Алиса описывает товары по следующей схеме:

### Слой A — Идентификация (всегда)
"{Название}."

**Важно:** Алиса НЕ повторяет код товара в ответе, так как пользователь уже его назвал.

### Слой B — Описание (главное)
Если поле "Описание (для Алисы)" заполнено:
"{Описание (для Алисы)}."

### Слой C — Факты (3–5 максимум, только если заполнены)
В таком порядке:
1. Цвет
2. Материал
3. Размеры
4. Вес
5. Комплектация

Пример:
"Основные параметры: цвет — хром, материал — латунь, размеры: Длина 61,4 см, Высота 4 см, В комплекте: монтажный комплект, инструкция."

## Поддерживаемые форматы ввода артикула

### 1. Прямой ввод цифрами
```
"9574610"
"артикул 9574610"
"код товара 9574610"
```

### 2. Произнесение по одной цифре (рекомендуется)
```
"девять пять семь четыре шесть один ноль"
"артикул девять пять семь четыре шесть один ноль"
"код девять пять семь четыре шесть один ноль"
```

### 3. Частичный артикул (последние 5+ цифр)
```
"74610"
"семь четыре шесть один ноль"
```

## Примеры использования

### Пример 1: Полный артикул
**Пользователь:** "Артикул девять пять семь четыре шесть один ноль"

**Алиса:** "Держатель для полотенца Lauter. Настенный держатель для полотенец в ванную создает удобное место для банных принадлежностей. Конструкция из латуни с покрытием цвета хром демонстрирует устойчивость к воздействию влаги. Металлические крепления и монтаж на болтах или саморезах обеспечивают надежную фиксацию на стене. Основные параметры: цвет — хром, материал — латунь, размеры: Длина 61,4 см, Высота 4 см, В комплекте: монтажный комплект, инструкция."

### Пример 2: Частичный артикул
**Пользователь:** "Семь четыре шесть один ноль"

**Алиса:** "Держатель для полотенца Lauter. Настенный держатель для полотенец в ванную..."

### Пример 3: Товар не найден
**Пользователь:** "Один два три четыре пять шесть семь"

**Алиса:** "Не удалось распознать артикул. Назовите артикул товара, например: артикул девять пять семь четыре шесть один ноль."

## Технические детали

### Структура базы данных
База данных товаров хранится в формате JSON: `/config/products.json`

Поля товара:
- `Код товара` - уникальный артикул (число)
- `Название` - название товара
- `Цвет` - цвет товара (опционально)
- `Материал` - материал изготовления (опционально)
- `Размеры` - размеры товара (опционально)
- `Вес` - вес товара (опционально)
- `Комплектация` - комплектация товара (опционально)
- `Описание (для Алисы)` - текстовое описание для голосового ассистента
- `Ссылка` - ссылка на товар на сайте

### Обновление базы данных
Для обновления базы данных товаров:

1. Обновите Excel файл: `/Все товары/Описание ДОМа_идеально_для_Алисы_v3.xlsx`
2. Запустите скрипт конвертации:
   ```bash
   cd "/Users/kikanbig/21vek/Алиса"
   source venv/bin/activate
   python scripts/convert_products_to_json.py
   ```
3. Перезапустите навык Алисы

### Тестирование

## Рекомендации для пользователей

1. **Произносите артикул по одной цифре** - это самый надежный способ
2. **Говорите четко** - Алиса лучше распознает отдельные цифры
3. **Используйте ключевые слова** - "артикул", "код товара" помогают Алисе понять намерение
4. **Минимум 5 цифр** - для поиска нужно минимум 5 последних цифр артикула

## Известные ограничения

1. Произнесение артикула десятками ("девяносто пять") не поддерживается - используйте произнесение по одной цифре
2. Произнесение артикула сотнями ("девятьсот пятьдесят") не поддерживается - используйте произнесение по одной цифре
3. Минимальная длина артикула для поиска - 5 цифр
4. Частичный поиск работает только по последним цифрам артикула
