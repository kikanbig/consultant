# Навык Алисы для торгового зала

## Описание проекта
Голосовой навык для Яндекс Алисы, предназначенный для информирования покупателей о товарах в торговом зале.

## Основные функции
- 🛋️ Информация о товарных группах и характеристиках
- 🔍 **Поиск товаров по артикулу** - голосовой поиск с произнесением по цифрам
- 💰 Актуальные акции и специальные предложения
- 👥 Направление к консультанту при необходимости
- 📊 Сбор обратной связи от покупателей
- 🎯 **Персонализация контента по устройствам** - разный контент на разных колонках!
- 😄 **15 весёлых ответов** - дружелюбные и с юмором ответы на неизвестные вопросы

## Технический стек
- **Backend**: Node.js + Express
- **База данных**: JSON файлы с товарами (3512 товаров)
- **Платформа**: Яндекс.Диалоги
- **Деплой**: Yandex Cloud Functions / Railway
- **Обработка данных**: Python (конвертация Excel → JSON)

## Примеры диалогов

- **Пользователь**: "Артикул девять пять семь четыре шесть один ноль"
- **Алиса**: "По коду 9 5 7 4 6 1 0 — товар: Держатель для полотенца Lauter. Коротко: Настенный держатель для полотенец в ванную создает удобное место для банных принадлежностей. Конструкция из латуни с покрытием цвета хром демонстрирует устойчивость к воздействию влаги. Основные параметры: цвет — хром, материал — латунь, размеры: Длина 61,4 см, Высота 4 см, В комплекте: монтажный комплект, инструкция."

### Общий диалог:
- **Пользователь**: "Алиса, расскажи о диванах"
- **Алиса**: "У нас представлены угловые, прямые и модульные диваны. Какой тип вас интересует?"

### Персонализация по зонам:

- **На колонке в гостиной**: "Добро пожаловать в гостиную! Здесь диваны, кресла..."

## Установка и запуск

### Первоначальная установка
```bash
# Установка Node.js зависимостей
npm install

# Создание виртуального окружения Python для обработки данных
python3 -m venv venv
source venv/bin/activate
pip install openpyxl pandas

# Конвертация базы данных товаров
python scripts/convert_products_to_json.py

# Запуск навыка
npm start
```

### Обновление базы данных товаров
```bash
# 1. Обновите Excel файл: Все товары/Описание ДОМа_идеально_для_Алисы_v3.xlsx
# 2. Запустите конвертацию:
source venv/bin/activate
python scripts/convert_products_to_json.py
# 3. Перезапустите навык
```

### Тестирование поиска товаров
```bash
# Полный набор тестов
node scripts/test_product_search.js

# Реалистичные сценарии
node scripts/test_realistic_scenarios.js

# Тест одного товара
node scripts/test_single_product.js "девять пять семь четыре шесть один ноль"
```

## 🚀 Быстрый деплой на Railway

**Railway** - рекомендуемая платформа для деплоя:

1. **Подключите GitHub репозиторий** к [railway.app](https://railway.app)
