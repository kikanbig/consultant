### 📝 Схема описания товара

Алиса описывает товары по трехслойной схеме:

**Слой A — Идентификация (всегда):**
- "По коду {Код товара} — товар: {Название}."
- Код произносится по одной цифре: "9 5 7 4 6 1 0"

**Слой B — Описание (главное):**
- "Коротко: {Описание (для Алисы)}."

**Слой C — Факты (3–5 максимум):**
- Цвет, Материал, Размеры, Вес, Комплектация

### 🎤 Поддерживаемые форматы ввода

1. **Произнесение по одной цифре** (рекомендуется):
   - "девять пять семь четыре шесть один ноль"
   - "артикул девять пять семь четыре шесть один ноль"

2. **Прямой ввод цифрами**:
   - "9574610"
   - "артикул 9574610"

3. **Частичный артикул** (последние 5+ цифр):
   - "74610"
   - "семь четыре шесть один ноль"

## Технические детали

### База данных
- **Источник**: `/Все товары/Описание ДОМа_идеально_для_Алисы_v3.xlsx`
- **Формат хранения**: `/config/products.json`
- **Количество товаров**: 3512

### Поля товара
- `Код товара` - уникальный артикул (число)
- `Название` - название товара
- `Цвет` - цвет товара (опционально)
- `Материал` - материал изготовления (опционально)
- `Размеры` - размеры товара (опционально)
- `Вес` - вес товара (опционально)
- `Комплектация` - комплектация товара (опционально)
- `Описание (для Алисы)` - текстовое описание для голосового ассистента
- `Ссылка` - ссылка на товар на сайте

### Алгоритм работы

1. **Преобразование слов в цифры**
   - Распознавание произнесенных цифр ("девять" → "9")
   - Поддержка различных вариантов произнесения

2. **Извлечение артикула**
   - Удаление пробелов между цифрами
   - Поиск последовательности из 5-7 цифр
   - Поддержка частичного поиска

3. **Поиск в базе данных**
   - Точное совпадение по коду товара
   - Частичное совпадение по последним цифрам

4. **Генерация ответа**
   - Формирование описания по схеме
   - Произнесение кода по одной цифре
   - Добавление только заполненных параметров

## Примеры использования

### Пример 1: Успешный поиск
```
Пользователь: "Артикул девять пять семь четыре шесть один ноль"

Алиса: "По коду 9 5 7 4 6 1 0 — товар: Держатель для полотенца Lauter. 
Коротко: Настенный держатель для полотенец в ванную создает удобное место 
для банных принадлежностей. Конструкция из латуни с покрытием цвета хром 
демонстрирует устойчивость к воздействию влаги. Основные параметры: 
цвет — хром, материал — латунь, размеры: Длина 61,4 см, Высота 4 см, 
В комплекте: монтажный комплект, инструкция."
```

### Пример 2: Товар не найден
```
Пользователь: "Один два три четыре пять шесть семь"

Алиса: "Товар с кодом 1 2 3 4 5 6 7 не найден в базе данных. 
Проверьте правильность артикула или обратитесь к консультанту."
```

## Обновление базы данных

### Процесс обновления:
1. Обновить Excel файл с товарами
2. Запустить скрипт конвертации:
   ```bash
   source venv/bin/activate
   python scripts/convert_products_to_json.py
   ```
3. Перезапустить навык Алисы

### Автоматизация:
Можно настроить автоматическую конвертацию при изменении Excel файла или по расписанию.

## Известные ограничения

1. **Произнесение десятками и сотнями не поддерживается**
   - Не работает: "девяносто пять" (будет неправильно распознано)
   - Работает: "девять пять" (по одной цифре)

2. **Минимальная длина артикула - 5 цифр**
   - Артикулы короче 5 цифр не распознаются

3. **Частичный поиск только по последним цифрам**
   - Поиск по первым или средним цифрам не поддерживается
